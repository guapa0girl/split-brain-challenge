# 🧠 SplitBrain Challenge

**SplitBrain Challenge**는 웹캠 앞 허공에 양손 검지손가락을 이용해 동시에 서로 다른 도형을 그리는 **좌우뇌 독립 제어(멀티태스킹) 한계 테스트 게임**입니다.
MediaPipe의 실시간 손가락 추적 기술과 OpenCV의 수학적 도형 판별 알고리즘을 결합하여, 사용자의 손가락 궤적을 실시간으로 분석하고 채점합니다.

## ✨ 주요 기능 및 특징 (Key Features)

- **✋ 실시간 양손 추적 (Real-time Hand Tracking)**: 웹캠을 통해 양손 검지손가락의 좌표를 프레임 단위로 추출합니다. (거울 모드 지원)
- **🧠 완전 독립형 멀티태스킹 평가**: 양손의 성공 횟수를 개별적으로 관리하여, 한 손이 미션을 먼저 달성해도 다른 손은 게임을 계속 진행할 수 있는 완벽한 비동기식 채점 시스템을 구현했습니다.
- **📐 엄격한 도형 판별 알고리즘**: 사용자의 꼼수(작게 그리기, 선만 긋고 돌아오기 등)를 방지하기 위해 `Convex Hull`로 손떨림 노이즈를 제거하고, `approxPolyDP`를 통해 오차 범위를 계산하여 도형의 꼭짓점을 깐깐하게 채점합니다.
- **🎨 동적 UI 및 점선 가이드**: 사용자가 직관적으로 미션을 수행할 수 있도록 중앙 정렬된 텍스트와 동적 색상 변화, 수학적 삼각함수 연산을 통해 실시간으로 렌더링되는 3배율 대칭형 점선 가이드를 제공합니다.

## 🛠 필수 라이브러리 및 설치 방법 (Prerequisites)

이 프로젝트를 실행하기 위해서는 아래의 파이썬 라이브러리가 필요합니다. 가상환경(예: conda `cv` 환경 등)을 활성화한 후 아래 명령어를 통해 설치해 주세요.

```bash
pip install opencv-python mediapipe numpy

```

## 🚀 실행 방법 (How to Run)

터미널에서 프로젝트 폴더로 이동한 뒤, 메인 파이썬 파일을 실행합니다.

```bash
python main.py

```

- **게임 시작**: 양손 검지손가락을 화면 중앙의 `START` 버튼 위에 1초간 올려두면 게임이 시작됩니다.
- **조작 방법**: 화면에 나타나는 동그란 시작점(Anchor)에 손가락을 넣었다가 밖으로 빼면서 미션 도형을 따라 그리고, 다시 시작점으로 돌아오면 자동으로 채점됩니다.
- **게임 종료**: 게임 도중 언제든지 `ESC` 키를 누르면 안전하게 종료됩니다.

## 📁 파일 구성 및 모듈별 역할 (File Structure & Modules)

객체 지향 프로그래밍(OOP)의 단일 책임 원칙(SRP)과 합성(Composition) 원칙을 준수하여, 각 모듈이 독립적으로 역할을 수행하도록 설계되었습니다.

### 1. `main.py` (프로세스 제어 및 메인 루프)

- **역할**: 프로그램의 진입점(Entry Point)으로, 각 기능별로 분리된 모듈들을 연결하여 전체 시스템을 구동하는 컨트롤러입니다.
- **내용**:
- 웹캠 영상(OpenCV `VideoCapture`)을 프레임 단위로 읽어오고 좌우 반전을 적용합니다.
- `hand_tracker`, `shape_recognizer`, `game_manager`, `ui_renderer` 객체를 생성하여 연결합니다.
- 무한 루프 속에서 **손가락 좌표 추출 ➔ 게임 상태 업데이트 ➔ 화면 렌더링**의 3단계를 통제합니다.

### 2. `hand_tracker.py` (손가락 좌표 추적 모듈)

- **역할**: MediaPipe Hands API의 복잡한 내부 동작을 캡슐화(Encapsulation)하여, 화면 속 양손의 위치를 추적합니다.
- **내용**:
- 수많은 관절 중 검지손가락 끝(Landmark 8번)의 좌표만을 추출하며, 정규화된 비율(0.0~1.0)을 실제 웹캠 해상도 픽셀 좌표 정수형으로 변환합니다.
- 왼손과 오른손을 명확히 구분하여 `(x, y)` 형태의 독립적인 좌표 쌍을 반환합니다.

### 3. `shape_recognizer.py` (수학적 궤적 및 도형 판별 모듈)

- **역할**: 사용자의 궤적 좌표를 누적하고, 수학적 분석을 통해 어떤 도형인지 판별하는 두뇌 모듈입니다.
- **내용**:
- **직선 판별 (1라운드)**: 궤적의 경계 상자(Bounding Box)를 계산하여, 이동 거리(`dx`, `dy`) 비율로 꼼수 선 긋기를 차단합니다.
- **다각형 판별 (2, 3라운드)**: 파이썬 리스트를 `numpy` 배열로 변환 후, `cv2.approxPolyDP`를 사용하여 다각형을 근사화하고 꼭짓점 개수로 판별합니다.
- **엄격한 꼼수 방지**: `cv2.convexHull`로 궤적을 팽팽하게 펴주고, `cv2.contourArea`를 계산하여 앵커 밖에서 점만 찍고 돌아오는 행위를 무효 처리합니다.

### 4. `game_manager.py` (상태 머신 및 독립 라운드 관리 모듈)

- **역할**: 게임의 진행 상태(State)를 제어하고, 완벽히 독립적인 멀티태스킹 룰을 관리합니다.
- **내용**:
- `WAITING`, `PLAYING`, `ROUND_CLEAR`, `CLEARED` 4가지 상태의 유한 상태 기계(FSM) 구조를 갖습니다.
- 양손 시작점(Anchor)의 충돌 판정을 관리합니다. 앵커를 벗어나면 궤적 기록을 시작하고, 돌아오면 채점합니다.
- 3라운드 성공 시 불필요한 전환 화면 없이 곧바로 최종 클리어 상태로 직행하도록 최적화되어 있습니다.

### 5. `ui_renderer.py` (시각 효과 및 인터페이스 모듈)

- **역할**: 그리기 함수들과 수학적 계산(`math.hypot`, 삼각함수)을 이용해 그래픽 요소를 렌더링합니다.
- **내용**:
- 텍스트 크기를 계산하여 항상 화면 정중앙에 위치하도록 **자동 중앙 정렬**을 수행합니다.
- 시작점을 첫 번째 꼭짓점으로 삼아, 시원하게 뻗어 나가는 **대칭형 점선 가이드**를 렌더링합니다.
- 진행 상태에 따라 앵커의 색상을 동적(초록 ➔ 빨강 ➔ 노랑)으로 변화시킵니다.
