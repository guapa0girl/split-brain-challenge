### 📁 필요한 파일 구성 및 역할

**1. `main.py` (프로세스 제어 및 메인 루프)**

- **역할**: 프로그램의 진입점으로 전체 시스템을 구동합니다.
- **내용**: 웹캠 영상(OpenCV `VideoCapture`)을 프레임 단위로 읽어오는 `while` 루프가 있습니다. 내부에서 아래의 모듈들을 인스턴스화(객체 생성)하여 조립(Composition)하고, 손가락 좌표를 추출하여 게임 로직에 전달한 뒤, 최종 화면을 띄우는 뼈대 역할을 합니다.

**2. `hand_tracker.py` (손가락 좌표 추적 모듈)**

- **역할**: MediaPipe Hands 라이브러리를 활용하여 화면 속 손을 감지합니다.
- **내용**: 카메라 프레임을 입력받아 양손의 랜드마크(관절 위치)를 분석합니다. 수많은 관절 중 **검지손가락 끝(Landmark 번호 8번)**의 X, Y 좌표만 정제하여 `main.py`로 반환하는 기능에만 집중합니다. 왼손과 오른손을 구분하여 독립적인 좌표 쌍을 내보내야 합니다.

**3. `shape_recognizer.py` (도형 및 궤적 판별 모듈)**

- **역할**: 손가락이 지나간 궤적 좌표들을 분석하여 어떤 모양인지 판별하는 알고리즘 핵심 모듈입니다.
- **내용**:
  - **선 판별**: 궤적의 시작점과 끝점을 이은 기울기와, 궤적 중간의 이탈률을 계산하여 가로선인지 세로선인지 판별합니다.
  - **도형 판별**: 손가락이 머무르거나 뗀 시점의 좌표 리스트를 `numpy` 배열로 변환합니다. `cv2.approxPolyDP` 함수를 사용해 이 궤적을 근사화된 다각형으로 만들고, 검출된 꼭짓점의 개수에 따라 삼각형(3), 사각형(4), 오각형(5)으로 분류합니다.

**4. `game_manager.py` (게임 상태 및 라운드 관리 모듈)**

- **역할**: 게임의 진행 상황(State)과 점수, 라운드 클리어 여부를 전담하여 관리합니다.
- **내용**: 현재 화면이 '대기 상태(START 버튼 활성화)'인지, '1/2/3 라운드 진행 중'인지, '종료' 상태인지를 추적합니다. 각 라운드마다 양손이 각각 도형을 올바르게 그렸는지 체크하고, 성공 횟수 변수를 +1씩 증가시킵니다. 양손 모두 연속 3회 달성 시 다음 라운드로 상태를 전환시키는 로직을 포함합니다.

**5. `ui_renderer.py` (시각 효과 및 인터페이스 모듈)**

- **역할**: OpenCV의 그리기 함수(`cv2.putText`, `cv2.rectangle`, `cv2.line` 등)들을 이용해 화면에 그래픽 요소를 덧입히는 역할을 합니다.
- **내용**:
  - 게임 시작 시 화면 중앙에 나타나는 "START" 버튼 영역 그리기.
  - 화면 중앙 상단의 현재 라운드 텍스트 출력.
  - 좌우 상단에 이번 라운드에서 그려야 할 선/도형 가이드 텍스트 표시.
  - 손가락 이동 경로에 따라 실시간으로 화면에 선이 그려지는 시각 효과 처리.
  - 인터페이스에 관련된 모든 코드를 이 파일에 모아두면, 메인 로직이 지저분해지는 것을 방지할 수 있습니다.
